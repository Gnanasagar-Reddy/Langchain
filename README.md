# LangChain – Generative AI

A hands-on exploration of **LangChain and Generative AI**, using Google Gemini to build LLM-powered applications and understand the fundamentals of AI orchestration and agentic systems.

## Topics Covered

- **LLM Integration:** Google Gemini with LangChain.
- **Prompt Engineering:** Chat prompts and message types.
- **LCEL & Runnables:** Sequential, parallel, conditional and custom chains.
- **Structured Outputs:** Output parsers and Pydantic models.
- **Tool Calling:** Custom tools and LLM tool binding.
- **AI Agents:** ReAct agents and automated tool execution.
- **Web Search:** DuckDuckGo and Wikipedia integrations.
- **SQL Agents:** Natural-language interaction with SQLite databases using SQLDatabaseToolkit.

## Tech Stack

`Python` · `LangChain` · `Google Gemini` · `LangGraph` · `SQLite` · `SQLAlchemy` · `Pydantic` · `UV`

## Objective

Explore LLM orchestration, tool calling, agentic workflows and database integration while building a strong foundation for real-world Generative AI applications.
